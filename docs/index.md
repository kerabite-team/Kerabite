# Kerabite

Kerabite adalah aplikasi edukasi pangan lokal untuk pelajar sekolah menengah. Aplikasi ini dibuat oleh tim siswa MAN 2 Kota Malang dengan pendampingan guru sebagai proyek untuk mengikuti kompetisi.
